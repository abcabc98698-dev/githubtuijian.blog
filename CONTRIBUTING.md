# Contributing to GitHubTuijian

Thank you for your interest in contributing to GitHubTuijian! We welcome contributions from everyone.

## How to Contribute

### 1. Fork & Clone

1. Fork the repository.
2. Clone your fork locally: `git clone https://github.com/YOUR_USERNAME/githubtuijian-blog.git`
3. Navigate into the directory: `cd githubtuijian-blog`

### 2. Setup

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`

### 3. Make Changes

1. Create a new branch: `git checkout -b feature/your-feature-name`
2. Verify that your changes build cleanly: `npm run build`

### 4. Code Standards

- We use Tailwind CSS v4 and standard CSS custom properties.
- Keep client JavaScript to an absolute minimum to preserve 100/100 Core Web Vitals.
- Ensure all new pages include appropriate metadata and Schema.org markup.
