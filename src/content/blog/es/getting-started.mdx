Bienvenido a **GitHubTuijian** — una plataforma independiente y arquitectura de referencia diseñada específicamente para la selección de proyectos de código abierto y la ingeniería web de alto rendimiento. Esta guía te orientará en los pilares arquitectónicos, la configuración técnica y las mejores prácticas de despliegue.

## ¿Qué Hace Diferente a Esta Arquitectura?

A diferencia de los sitios web convencionales que tratan el SEO y los Core Web Vitals como un añadido secundario, nuestra arquitectura se estructura sobre tres pilares esenciales:

1. **SEO Técnico**: Generación automatizada de esquemas JSON-LD, URLs canónicas dinámicas, sitemaps y soporte riguroso de hreflang multilingüe.
2. **GEO (Generative Engine Optimization)**: Contenido estructurado semánticamente para facilitar la indexación y citación por motores de búsqueda con inteligencia artificial.
3. **AEO (Answer Engine Optimization)**: Bloques de definición optimizados para fragmentos destacados (Featured Snippets) y respuestas directas.

## Pila Tecnológica Central

Nuestra base técnica aprovecha herramientas modernas de código abierto:

- **Generación de Sitios Estáticos (SSG)**: HTML prerenderizado con casi cero sobrecarga de JavaScript en tiempo de ejecución.
- **Tailwind CSS v4**: Variables CSS nativas, paletas de color OKLCH y tipografía tipificada.
- **Modo Oscuro Accesible**: Conmutación instantánea basada en clases sin destellos de contenido sin estilo (FOUC).
- **Content Collections de TypeScript**: Esquemas fuertemente tipados para artículos, casos de éxito y perfiles editoriales.
- **Activos Autoalojados**: Fuentes e imágenes servidas localmente sin dependencias externas de rastreo o CDN de terceros.

## Flujo de Desarrollo Local

```bash
# Clonar el repositorio
git clone https://github.com/githubtuijian/blog.git
cd blog

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```
